How to write a clearer AI prompt

A useful prompt explains the role, task, context, audience, constraints and desired output. Start with the result you need, then add details that help the assistant respond.

How to make business emails easier to read

Use a specific subject, state the purpose early, keep paragraphs short and make the next action clear. Review names, dates and attachments before sending.
