AI ToolBox starter website source

Included: responsive English homepage, 8 tool pages, 4 basic browser-based tools, About, Privacy, Contact, Guides, robots.txt and sitemap.xml.

Before publishing:
1. Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml with the deployed domain.
2. Add a real contact email and update the privacy policy to reflect actual services.
3. AI Writer, Text Rewriter, Grammar Checker and Translator are roadmap placeholders, not working AI services.
4. Prompt Generator and Email Writer create templates locally and do not call an AI model.
5. Do not add AdSense code until the site has substantial original content and meets current Google policies.
6. Static deployment: no build command; publish the project root.

This is a first design prototype, not a finished AdSense-ready business.
